Improvement proposals and future direction for BeamLabCountries.

Currently 23 locales (ar, cs, de, en, es, et, fr, hi, id, it, ja, ko, nl, pl, pt, ro, ru, sv, th, tr, uk, vi, zh).

### Unions / International Organizations
Currently 29 unions (eu, nato, g7, g20, brics, schengen, eurozone, etc.).
- [x] Add ASEAN
- [x] Add African Union (AU)
- [x] Add CIS (Commonwealth of Independent States)
- [x] Add OIC (Organisation of Islamic Cooperation)
- [x] Add Pacific Alliance
- [x] Add Mercosur

### Country Data Enhancements
- [x] Flag emoji as a first-class field on Country struct (already exists as `flag` field)
- [x] Dialing / calling codes per country (already exists as `country_code` field)
- [x] Latitude/longitude centroids or bounding boxes (already exists as `geo` field)
- [x] Time zone information
- [ ] Country-to-country border relationships
- [x] Currency formatting helpers (symbol, decimal places)
